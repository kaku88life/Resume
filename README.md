# Resume - Kuo Tzu-Jui

Interactive resume website built for applying to Rebas (野球革命) Backend Engineer position.

## Live

https://kaku88life.github.io/Resume/

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS (v4)
- GitHub Pages (GitHub Actions deploy)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## About

Built with Vibe Coding (Claude Code). All content is in `src/data/resume-data.ts`.
